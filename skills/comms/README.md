# Comms

寫給特定人類讀者 —— 工程同事、非工程同事、會議參與者。預設出 draft，由你送出。

**User-invoked** — reachable only when you type them.

- **[generate-meeting-notes](./generate-meeting-notes/SKILL.md)**: 把逐字稿、字幕或錄音轉成結構化繁中會議記錄，發佈到 Google Doc 與 Slack

**Model-invoked** — the model can reach for these when the description matches.

- **[slack-pm](./slack-pm/SKILL.md)**: 把要發給非工程師同事（PM／AM／業務／主管）的 Slack 訊息寫成交辦簡述
- **[slack-rd](./slack-rd/SKILL.md)**: 把要發給 RD team 的 Slack 訊息寫成公告 + thread 論述兩層，預設產出 draft

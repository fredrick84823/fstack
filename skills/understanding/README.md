# Understanding

提高人類理解的效率。兩個半邊，同一個目的：

| | 手段 | 產出 |
|---|---|---|
| **深度** | 把散落來源編譯成新結構 | 你原本沒有的東西 |
| **速度** | 換一種呈現方式 | 同樣的東西，讀得更快 |

`knowledge-map` 兩邊都沾 —— 它同時編譯結構又把結構畫出來。

## 深度 — 編譯出新結構

- **[topic-dictionary](./topic-dictionary/SKILL.md)**: Build a dependency-aware concept dictionary in learning order
- **[personal-wiki-mine](./personal-wiki-mine/SKILL.md)**: Mine mechanism-first candidate claims from a bounded set of sources
- **[knowledge-map](./knowledge-map/SKILL.md)** *(user-invoked)*: Build a visual-first learning map from your learning target and current state

## 速度 — 換一種呈現

- **[doc-to-html](./doc-to-html/SKILL.md)** *(user-invoked)*: Convert RFCs, design docs, PRDs and research notes into readable single-page HTML
- **[viz-it](./viz-it/SKILL.md)** *(user-invoked)*: Turn any content into a visual-first single-page HTML where every diagram is a pan/zoom canvas
- **[beautiful-mermaid](./beautiful-mermaid/SKILL.md)** *(user-invoked)*: Render restrained, Craft-style Mermaid diagrams (SVG / interactive HTML / ASCII)

`beautiful-mermaid` 比另外兩支低一層 —— 它是圖的渲染元件，`doc-to-html` 與 `viz-it` 都會用到。

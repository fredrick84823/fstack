# TUI 實際渲染什麼

2026-09-10 在 Claude Code 2.1.267 · WezTerm · truecolor · UTF-8 實測。
官方 issue #26390 列的「壞掉清單」已經過期一半 —— 以這份為準。

## 會渲染

| 語法 | 結果 |
|---|---|
| 表格 | 完整框線表格，**CJK 欄寬正確** |
| fenced code block | 語法高亮 |
| diff block | +/- 紅綠 |
| code span | 等寬上色 |
| 巢狀清單 | 逐層縮排 |
| 巢狀引言 | 逐層縮排 + 直線 |
| 連結 `[標籤](url)` | 標籤保留 |
| 刪除線 `~~x~~` | 真的劃掉 |
| box-drawing `┌─│└` | 對齊正確，WezTerm 畫成連續線 |

中文字型不合成斜體，所以 `*斜體*` 在中文上看不出來；英文可以。

## 不渲染

| 語法 | 實際顯示 | 改用 |
|---|---|---|
| `- [x]` / `- [ ]` | 字面 `- [x]`，連圓點都沒了 | ✅ / ❌ 符號，或表格一欄 |
| `---` 分隔線 | 字面三個 dash | 空行，或一個小標題 |
| `&amp;` `&copy;` | 原樣 | 直接打 `&` `©` |
| `## / ### / ####` | 三層同一種粗體 | 表格或縮排帶階層 |

## 圖片

Claude Code 2.1.200–270 的 changelog 沒有任何終端圖片渲染條目。WezTerm 本身支援
iTerm2 圖片協定與 Sixel，但 TUI 這側沒有走那條路 —— 輸出只有文字。

## emoji

單一 emoji 與國旗、ZWJ 家族組合都顯示得出來，但 `🔸` 這類會退化成 `◆`，寬度隨字型
浮動。**別放進框線裡** —— `verify.py` 算得出宣告寬度，算不出你字型實際畫多寬。

# 逐字稿

**Speaker1**：今天三件事。第一件是匯入失敗訊息，上週說要帶行號跟欄位名，Speaker2 已經改好了。
**Speaker2**：改好了，也補了一組範例在文件裡。客戶那邊還沒回饋，因為他們這週沒有新的匯入。
**Speaker3**：那就先當作待驗證，等他們下次匯入再看。
**Speaker1**：第二件，回歸已經改吃那份 200 列樣本，跑起來兩分鐘，比之前快很多。
**Speaker3**：樣本那邊我還想再加一組全形數字的案例，客戶的舊檔很多是全形。
**Speaker1**：可以，加在同一份就好，不要另外開一份。
**Speaker2**：全形數字現在是直接當字串處理，加進去應該會紅。
**Speaker1**：紅了正好，那就是一個要修的。
**Speaker3**：第三件是報表的欄位順序。客戶說他們習慣把金額欄放最左邊。
**Speaker2**：欄位順序是設定檔控制的，改設定就好，不用動程式。
**Speaker3**：那可以請他們自己改嗎？
**Speaker2**：設定檔他們沒有權限，還是我們改。我下午改。
**Speaker1**：改完記得跟他們確認一次，不要改完他們才說要別的順序。
**Speaker3**：好，我來對。
**Speaker1**：今天就這樣。
